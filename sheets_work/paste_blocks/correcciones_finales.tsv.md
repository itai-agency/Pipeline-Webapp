## Corrección robusta para fechas como texto

### SEMANAL H2 alternativa robusta
```tsv
=MAP(A2:A,B2:B,LAMBDA(sem,cliente,SI(sem="",,SI.ERROR(SUMA(FILTRAR(RESPALDO_DIARIO!$AA:$AA,RESPALDO_DIARIO!$Z:$Z=cliente,FECHANUMERO(RESPALDO_DIARIO!$Y:$Y)>=FECHANUMERO(sem),FECHANUMERO(RESPALDO_DIARIO!$Y:$Y)<=FECHANUMERO(sem)+6)),0))))
```

### MENSUAL H2 alternativa robusta
```tsv
=MAP(A2:A,B2:B,LAMBDA(mes,cliente,SI(mes="",,SI.ERROR(SUMA(FILTRAR(RESPALDO_DIARIO!$AA:$AA,RESPALDO_DIARIO!$Z:$Z=cliente,TEXTO(FECHANUMERO(RESPALDO_DIARIO!$Y:$Y),"yyyy-mm")=TEXTO(FECHANUMERO(mes),"yyyy-mm"))),0))))
```
